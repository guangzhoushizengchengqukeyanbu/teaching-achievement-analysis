# 📊 区域教学成果智能分析与培育系统

> 基于生成式AI辅助开发的全流程数据分析工具集，为教学成果培育提供数据驱动、可视化、可复现的智能决策支持。

## 🎯 功能概述

本系统集成了10余个交互式数据分析页面，覆盖四大功能模块：

- **🌐 宏观总览**：全市333项教学成果的可视化大屏、关键词云图、LDA主题模型、社会网络分析
- **🎯 区域聚焦**：增城区与广州市的多维度对比分析，精准定位区域优势与短板
- **🔬 深度诊断**：对增城区19项成果进行逐项画像，提供个性化改进建议
- **🚀 培育赋能**：基于教育生态系统理论的“四阶八维”培育路径模型与三年行动计划

## 🚀 部署方式

1. 下载本仓库全部文件
2. 双击 `index.html` 即可运行
3. 无需安装任何依赖，无需服务器环境

## 🛠️ 技术栈

- HTML + CSS + JavaScript（纯前端，无框架依赖）
- ECharts 5.4.3 / Chart.js / D3.js v7（可视化）
- WordCloud2.js（词云生成）
- DeepSeek（AI辅助代码生成与数据分析）
